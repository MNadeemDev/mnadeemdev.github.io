About Me

소개

Full-time AI Research Engineer working on LLM/VLM and vision models end to end — from research and training through to optimized GPU inference. My current work covers agentic RAG systems (LangChain, tool calling, vector retrieval, answer evaluation), lightweight LLM/VLM fine-tuning with PyTorch and Hugging Face (Transformers, PEFT, LoRA/QLoRA), and inference optimization using quantization (INT8/4-bit), ONNX, TensorRT, OpenVINO, and vLLM/Ollama for resource-constrained GPUs and edge devices.

LLM/VLM 및 비전 모델을 연구·학습부터 GPU 추론 최적화까지 엔드투엔드로 담당하는 AI 연구 엔지니어입니다. 현재 에이전틱 RAG 시스템(LangChain, 툴 콜링, 벡터 검색, 답변 평가), PyTorch·Hugging Face(Transformers, PEFT, LoRA/QLoRA) 기반 경량 LLM/VLM 파인튜닝, 그리고 양자화(INT8/4-bit)·ONNX·TensorRT·OpenVINO·vLLM/Ollama를 활용한 추론 최적화를 수행하고 있습니다.

1. GaN Fab Process-Traceability RAG System — on-premise LLM + VLM (2026)

1. GaN 공정 이력추적 RAG 시스템 — 온프레미스 LLM + VLM (2026)

  • Built a fully on-premise Korean-language RAG assistant over a 14,024-chunk knowledge base combining 12,890 equipment trouble/maintenance records with a 314-page MES manual.
  • Designed three-signal hybrid retrieval — BGE-M3 dense vectors, BM25 with a Korean syllable-bigram tokenizer, and a multi-hop knowledge graph traversed by Personalized PageRank — fused with Reciprocal Rank Fusion, then reranked top-30→top-5 by a cross-encoder, returning every answer with citations.
  • Used Qwen2.5-VL 7B to describe manual screenshots (menu trees, buttons, highlighted regions, table columns), making content that exists only inside images retrievable as text.
  • Domain-adapted the generator with LoRA and 4-bit QLoRA via Hugging Face PEFT; merged adapters and converted to GGUF (llama.cpp) for Ollama serving.
  • Engineered a 5-step chain-of-thought root-cause-analysis prompt and automated traceability / RCA / maintenance report generation with auto-generated citations.
  • Benchmarked candidate LLMs on an in-house RCA benchmark (cause accuracy, numeric fidelity, citation compliance, Korean fluency) to select the deployed model.
  • Stack: HyperCLOVA X SEED, Qwen2.5-VL 7B, BGE-M3, bge-reranker-v2-m3, Hugging Face PEFT, Ollama, llama.cpp/GGUF, PP-StructureV3.
  • 장비 트러블·정비 이력 12,890건과 314페이지 MES 매뉴얼을 결합한 14,024청크 지식베이스 기반의 완전 온프레미스 한국어 RAG 어시스턴트 구축.
  • 3신호 하이브리드 검색 설계 — BGE-M3 임베딩, 한글 음절 bigram BM25, Personalized PageRank 기반 멀티홉 지식그래프 — 를 RRF로 융합하고 크로스인코더로 상위 30건→5건 재순위화하여 인용과 함께 답변 제공.
  • Qwen2.5-VL 7B로 매뉴얼 스크린샷(메뉴 트리, 버튼, 강조 영역, 표 컬럼)을 설명 생성하여 이미지 내부 정보까지 검색 가능하도록 구현.
  • Hugging Face PEFT의 LoRA 및 4비트 QLoRA로 생성 모델을 도메인 적응하고, 어댑터 병합 후 GGUF(llama.cpp)로 변환해 Ollama에서 서빙.
  • 5단계 CoT 근본원인 분석 프롬프트를 설계하고 이력추적·RCA·정비 보고서를 인용과 함께 자동 생성.
  • 사내 RCA 벤치마크(원인 판정, 수치 보존, 인용 규칙, 한국어 품질)로 후보 LLM을 평가하여 배포 모델 선정.
  • 기술: HyperCLOVA X SEED, Qwen2.5-VL 7B, BGE-M3, bge-reranker-v2-m3, Hugging Face PEFT, Ollama, llama.cpp/GGUF, PP-StructureV3.

2. SpectroFire — Zero-Shot EO/IR Vision-Language Recognition (ACPR 2025, ICOIN 2026)

2. SpectroFire — 제로샷 EO/IR 비전-언어 인식 (ACPR 2025, ICOIN 2026)

  • Built a CLIP-style dual-encoder over EO + thermal-IR imagery for zero-shot recognition, classifying by cosine similarity against prompt embeddings so new target classes are added by writing a prompt — no retraining.
  • Added cross-spectral registration, temporal synchronization, density-based geolocation, and structured event messaging, with automatic CUDA/CPU device selection for Jetson deployment.
  • Combined real-time edge inference with IoT data networking for distributed monitoring (ICOIN 2026).
  • Stack: CLIP-style dual encoder, contrastive learning, prompt engineering, EO/IR fusion, PyTorch, Jetson.
  • EO + 열적외선(IR) 영상 기반 CLIP 스타일 듀얼 인코더를 구축해 제로샷 인식 구현. 프롬프트 임베딩과의 코사인 유사도로 분류하므로 재학습 없이 프롬프트 작성만으로 새로운 클래스 추가 가능.
  • 교차 스펙트럼 정합, 시간 동기화, 밀도 기반 위치추정, 구조화된 이벤트 메시징을 추가하고 Jetson 배포를 위한 CUDA/CPU 자동 선택 지원.
  • 실시간 엣지 추론과 IoT 데이터 네트워킹을 결합한 분산 모니터링 구현 (ICOIN 2026).
  • 기술: CLIP 스타일 듀얼 인코더, 대조 학습, 프롬프트 엔지니어링, EO/IR 융합, PyTorch, Jetson.

3. PA-Drive — End-to-End Autonomous Driving Planner (2026 Autonomous Driving AI Challenge)

3. PA-Drive — End-to-End 자율주행 플래너 (2026 자율주행 AI 챌린지)

  • Built a 6-camera end-to-end planner: scene encoder → K trajectory-query candidates from a Transformer decoder → differentiable physical objective (collision, lane, dynamics, comfort, progress) → hard-constraint filtering → ranking.
  • Cut planning L2 error from 1.902 to 0.246 on nuScenes across four iterations by relativizing the confidence gate, adding ego-conditioned kinematic anchors, and correcting three constraint definitions.
  • Eliminated temporal data leakage by moving from random frame splits to official nuScenes splits, and enforced FP16 autocast with an explicit FLOPs budget check for on-vehicle latency.
  • Related first-author paper on lightweight multi-scale fusion for real-time driving segmentation accepted at WACV 2026 (LLVM-AD workshop).
  • Stack: Transformer decoder, VAD/VADv2 scene encoder, nuScenes, FP16 autocast, Docker.
  • 6개 카메라 기반 End-to-End 플래너 구축: 씬 인코더 → Transformer 디코더의 K개 궤적 후보 → 미분 가능한 물리 목적함수(충돌·차선·동역학·승차감·진행도) → 하드 제약 필터링 → 랭킹.
  • 신뢰도 게이트 상대화, ego 조건부 운동학 anchor 도입, 제약조건 3종 수정을 통해 nuScenes Planning L2를 1.902에서 0.246으로 개선.
  • 무작위 프레임 분할을 nuScenes 공식 분할로 교체해 시계열 데이터 누수를 제거하고, FP16 autocast와 FLOPs 예산 검사를 적용해 차량 탑재 지연시간 확보.
  • 관련 제1저자 논문(실시간 주행 세그멘테이션을 위한 경량 멀티스케일 융합)이 WACV 2026 (LLVM-AD 워크숍)에 게재.
  • 기술: Transformer 디코더, VAD/VADv2 씬 인코더, nuScenes, FP16 autocast, Docker.

4. Manhole Worker Safety — Pose-Based Activity Tracking and Risk Fusion (ICRA 2027 submission)

4. 맨홀 작업자 안전 — 포즈 기반 활동 추적 및 위험도 융합 (ICRA 2027 투고)

  • Built worker activity tracking with pose estimation: per-person detection plus 17-keypoint skeletons tracked across frames from live RTSP/IP-camera feeds to monitor posture and activity inside confined spaces.
  • Implemented fall and immobility detection from tracked pose geometry — torso tilt beyond 55° from vertical or bounding-box aspect above 1.10, confirmed over 5 consecutive frames to suppress flicker — alongside an fps-normalized stillness detector flagging prolonged immobility.
  • Designed dual-track de-identification so a single pose model serves privacy and safety simultaneously: a monitoring track blurs or pixelates faces while keeping the body skeleton visible for fall judgment, and a storage track applies an irreversible solid mask. The face region is derived from facial keypoints with a shoulder-based fallback so no face is left unmasked in low light or backlit conditions.
  • Emitted a per-frame audit log (persons detected, faces masked, fallback usage, fall alarms) as compliance evidence for de-identification requirements.
  • Fused this camera-based worker state with a five-measurand gas array into a four-level risk lattice driving distinct response protocols, with every hazard decision made connectivity-independent at the edge node for underground sites without reliable wireless.
  • Benchmarked ONNX Runtime and OpenVINO inference latency (mean/p50/p90/p99) on an NPU-less 4-core Intel N100 board, and delivered the system with FastAPI services and an operator dashboard (live grid, map, history, mobile views, i18n).
  • Stack: YOLOv8/YOLO26-pose (Ultralytics), 17-keypoint skeleton tracking, OpenCV, RTSP, multi-sensor fusion, ONNX Runtime, OpenVINO, FastAPI, Intel N100 edge PC.
  • 포즈 추정 기반 작업자 활동 추적 구현: 실시간 RTSP/IP 카메라 영상에서 사람별 탐지와 17개 키포인트 스켈레톤을 프레임 단위로 추적하여 밀폐공간 내 자세와 활동을 모니터링.
  • 추적된 포즈 기하 정보로 쓰러짐·부동 상태 탐지 구현 — 몸통 기울기 55° 초과 또는 바운딩 박스 종횡비 1.10 초과를 5프레임 연속 확인하여 오탐 방지 — 및 fps 정규화된 정지 지속 탐지로 장시간 부동 상태 감지.
