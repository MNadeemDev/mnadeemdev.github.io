Selected Projects (Recruiter View)

주요 프로젝트 (리크루터용)

  • LLM RAG Platform: Built retrieval-augmented pipelines with LangChain for domain QA, including chunking, vector search, and answer evaluation.
  • Tiny Object Detection API: Developed and deployed lightweight detection services with optimized inference for small objects and edge constraints.
  • OCR with vLLM: Implemented high-throughput OCR and post-processing pipelines for noisy, real-world text.
  • Autonomous Driving Segmentation: Trained and evaluated segmentation models on driving datasets for robust scene understanding.
  • VLM / Visual Question Answering: Prototyped VQA workflows combining vision backbones and LLM reasoning.
  • Time-Series Forecasting: Built forecasting pipelines using N-BEATS, N-HiTS, and other deep learning models.
  • Production Delivery: Served models with FastAPI/Flask and built React dashboards for prediction visualization.
  • LLM RAG 플랫폼: LangChain 기반 도메인 QA용 RAG 파이프라인 구축(청킹, 벡터 검색, 답변 평가).
  • 소형 객체 탐지 API: 작은 객체에 최적화된 경량 탐지 서비스 개발 및 배포.
  • vLLM 기반 OCR: 실제 환경 텍스트에 대한 고처리량 OCR 및 후처리 파이프라인 구현.
  • 자율주행 세그멘테이션: 주행 데이터셋 기반 세그멘테이션 모델 학습/평가.
  • VLM / 시각적 질의응답: 비전 백본과 LLM 추론을 결합한 VQA 프로토타입 개발.
  • 시계열 예측: N-BEATS, N-HiTS 등 딥러닝 기반 모델로 예측 파이프라인 구축.
  • 프로덕션 제공: FastAPI/Flask 서빙 및 React 대시보드 시각화 구축.
